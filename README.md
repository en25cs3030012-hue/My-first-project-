# Health360: Comprehensive Healthcare Risk & Disease Analytics

Health360 is a responsive front-end portfolio demo exploring how a dashboard can present illustrative risk indicators related to chronic conditions such as heart disease, diabetes, and stroke.

## Features
- Responsive dashboard layout for desktop and mobile
- Summary metric cards
- Visual risk distribution and indicator bars
- Searchable sample patient table
- Clear responsible-use disclaimer

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Use the search field to filter the fictional sample records.

No build tools or dependencies are required. Google Fonts are loaded when internet access is available; the interface still works without them.

## Important safety note
This is an educational UI prototype only. All records and metric values are fictional. It does not diagnose, predict, or replace a healthcare professional. Do not enter real patient information or use this demo to make medical decisions.

## Tech stack
HTML5, CSS3, vanilla JavaScript.
